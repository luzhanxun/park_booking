DEMO ROUTE

一条完整的客户演示路径

小程序内的日期、时段、营位、订单与核销码在同一次浏览中保持联动，可直接演出“预约—支付—核销”闭环。

选择活动与日期

首页置顶显示平台主打活动 我有一亩田（重点展示标识），也可进入 主题活动列表选“春耕插秧体验”；在日期胶囊中挑日期，售罄或停售日期置灰不可选。

选择票种与数量

成人票 / 儿童票 / 亲子套票 用步进器加减，实时显示分票种余量与合计；超出单场限购会自动收紧并提示。

选择公园与时段

首页进入 公园露营，在“斗门水乡公园”选择 日期 + 时段，观察平面图营位状态随选择刷新。

点选营位并下单

点击 A03 弹出营位详情，确认价格与容量后进入订单确认，填写联系人与人数。

模拟支付与二维码

活动或营位均走 模拟微信支付，成功页生成本次订单的核销二维码；“我的预约”按业务类型同步出现新订单。

现场核销

切到 核销工作台，用演示码核销；再次核销会提示“已核销”，越权公园会提示拦截。

SPEC COVERAGE

对应需求文档的关键约束

原型把容易在开发阶段产生分歧的规则前置成可见界面，便于现场拍板。

活动内容与票价

活动管理与公园管理在左侧菜单分开；后台按活动维护内容、分类、日期时段与票种库存，平台主打活动置顶并标注重点展示。

票种与分日库存

一次预约锁定一个活动日期，可同时选多个票种；余量按分票种库存扣减，支持停售与恢复。

公园图文内容

公园管理可维护封面、相册（≤6 张）、一句话简介、详细介绍、亮点标签、预约须知与咨询电话，列表按完整度标「图文完整 / 待完善」。

活动内容与配图

活动编辑抽屉内分「内容与配图 / 票种与库存 / 日期与场次」三屏，边改边看小程序预览，保存后活动卡片与票种列表同步刷新。

保存前内容校验

名称、描述、相册与票种为必填；票种重名、库存小于已售、日期重复均会拦截并定位到出错分区。

统一订单模型

活动预约与露营预约共用订单结构与核销二维码，可按业务类型筛选、查询与导出。

公园自定义平面图

底图来自公园自有平面图；营位以矩形与多边形 SVG 热区呈现，不使用真实地图。

按日 + 时段排期

一次仅选一个日期与一个时段；整日与分时互斥，单订单仅一个营位。价格只维护在营位上（基础价 + 周末 / 节假日加价），公园与场次层面不再单独定价。

公共设施图层

道路、出入口、卫生间等仅作展示，可独立显隐；不参与预约与库存。

地图配置审批

草稿 → 提交审批 → 通过 / 驳回 → 发布；审批期间线上版本不变，编辑人与审批人分离。

现场核销与权限

核销员绑定公园，仅可核销授权范围；重复、取消、退款、过期订单均拦截并说明原因。

报表与导出

预约量、核销量、核销率、收入与退款趋势，可按公园与日期筛选并模拟导出明细。

如何浏览

  • 直接双击 ui_desgin/index.html 打开即可，所有页面为纯静态文件，无需本地服务器。
  • 小程序页左侧为屏目录，可一键跳转；模拟器内的底部 Tab、返回与按钮均可点击。
  • 后台页通过左侧菜单按“概览 / 主题活动 / 公园露营 / 财务与数据 / 系统”分组切换 13 个视图；活动管理内可切“活动内容与票种 / 活动订单 / 活动核销”三个页签，“编辑图文”“编辑活动”抽屉可改封面、相册、描述、介绍、标签、票种与日期，保存后列表即刷新。表格筛选、抽屉、地图编辑器图层与属性面板均可交互。
  • 每个列表视图右上角提供“正常 / 载入 / 空 / 异常”状态切换，用于确认异常与空态文案。
  • 设计规范页列出全部 token 与组件状态，可作为后续开发验收依据。
SCOPE NOTE

原型的边界

本原型用于需求沟通与规格确认，不连接后端、不接真实微信支付与地图服务。

  • 数据均为本地假数据，金额与二维码仅作展示。
  • 公园平面图为示意底图，最终以甲方提供的图纸替换。
  • 活动包场、多日连住与真实微信支付回调等“本期不做”能力，界面中不提供入口。
