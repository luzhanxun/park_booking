营位与价格

营位是下单的最小单位，一个订单只包含一个营位。价格只维护在营位上：基础价 + 周末 / 节假日加价，公园与场次层面不再单独定价。

评审要点

营位状态优先级：维护 / 锁定 > 已约满 > 剩余少量 > 可预约。 维护中的营位不出现在小程序选位列表，但历史订单仍显示原营位名称。 价格改动只对新订单生效，已支付订单金额不变。

活动管理

主题活动是独立业务线，与公园露营完全分开：维护活动内容（封面配图、描述、介绍、标签、相册）、票种与库存、日期与场次排期，并查看活动预约订单与现场核销记录。「我有一亩田」是平台主打主题活动，需在首页重点展示。

评审要点

活动预约流程为选日期 → 选票种与数量 → 提交并支付 → 现场核销。 一个活动订单对应 1 个日期与 1 个场次，可购买多个票种，合计不超过限购张数。 需与客户确认：票种是否按人群分别定价、库存是否按日期单独设置、包场方案是否走线下合同。
